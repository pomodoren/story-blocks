How a story is made

A story is a folder of plain files. The page you read is generated from them, so it stays reviewable and reproducible.

  1. Write the spineAuthor story.md: Markdown prose with block fences for maps, charts, galleries and more.
  2. Buildstoryblocks build --content /path/to/stories validates the spine and writes the matching story.yaml.
  3. PreviewRun the local app to read it here{% if not static_site %} — or edit visually in the editor{% endif %}.
  4. Exportstoryblocks export --content /path/to/stories produces a static site with relative links that works from any file host.

Reading the numbers

Every card summarises its story from the built artifact; hover a figure for the same hint.

Blocks
The building units of a story: text, maps, charts, media.
Block types
How many different kinds of block the story uses; a measure of variety.
Sections
Parts opened by a cover or a top-level heading; each is one stop in the section navigation.
Images
Blocks that carry a picture. Every meaningful image has alt text.
Data blocks
Interactive blocks beyond prose and media, such as maps, charts and tables.
Languages
The story plus any built translations, each served as its own page.
